  1. In VAETrainer.__init__, the regularization type and dimension are set:
    - self.reg_type specifies the attribute type (e.g., 'rhy_complexity', 'num_notes',
  'note_range')
    - self.reg_dim specifies which dimension in the latent space to align with the attribute
  2. In compute_reg_loss() (lines 122-152), the regularization loss is calculated by:
    - Computing the specified attribute values from the input score
    - Taking the values at the specified latent dimension from z: x = z[:, self.reg_dim]
    - Applying a regularization loss between this latent dimension and the attribute values
  3. For "joint" attribute penalties (lines 135-147), multiple attributes are aligned with
  different latent dimensions:
    - For 'joint', rhythmic complexity aligns with dimension 0 and note density with dimension 1
    - For 'joint_rhycomp_noterange', rhythmic complexity aligns with dimension 0 and note range
  with dimension 2

  The reg_loss_sign() method creates a penalty that encourages the latent dimension to preserve
  the relative ordering of musical samples according to the attribute value (similar to a ranking
   loss).

  This approach allows the model to create an interpretable latent space where specific
  dimensions correspond to meaningful musical attributes.
